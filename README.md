# الصرح التعليمي · ALSARH EDUCATIONAL SYSTEM

**المنظومة المتكاملة للتعليم والإدارة والحسابات.** نسخة أولية قابلة للتشغيل على الويب مع مصدر تطبيق Android وWindows. واجهة عربية RTL متجاوبة، 3 أيقونات في الصف على الهاتف، وهوية كحلي/ذهبي.

## الوظائف التي تعمل فعلاً في هذه النسخة

- إنشاء أول مؤسسة ومدير بكلمة مرور مشفرة، تسجيل الدخول والخروج وتغيير كلمة المرور، حسابات مستخدمين بأدوار مدير/مدير مدرسة/محاسب/معلم/ولي أمر/طالب.
- إدارة الطلاب والصفوف والشعب والمعلمين والمواد والدروس والكتب والواجبات والاختبارات والدرجات والحضور والجداول والتعاميم والمخزون والموظفين.
- ربط الصفوف والمواد والطلاب والمعلمين، وبوابة عرض محددة للصلاحيات. ربط ولي الأمر بالطلاب عبر `guardianUserId` وربط حساب الطالب بسجله.
- أقساط مدرسية وسندات تحصيل ومصروفات وميزان مراجعة **بقيود محاسبية مزدوجة فعلية**؛ منع السداد بما يتجاوز القسط وحماية تكرار الطلبات بمفتاح Idempotency.
- لوحة قيادة وتقارير مدرسية ومالية، طباعة سند قبض، نسخة احتياطية JSON لأعمال الأرشفة.
- تطبيق ويب قابل للتثبيت PWA؛ غلاف Android WebView وغلاف Windows Electron يفتحان رابط خادم المدرسة الآمن HTTPS.

## بدء العمل محليًا

يتطلب **Node.js 22.16.x** (تستخدم قاعدة البيانات SQLite المدمجة في Node بهذا الإصدار مع العلم `--experimental-sqlite`). لا حاجة إلى `npm install` للخادم والويب.

```bash
npm start
```

افتح `http://localhost:8787`، أنشئ المؤسسة وحساب مدير النظام أول مرة. البيانات في `data/alsarh.sqlite` وليست مرفوعة إلى GitHub.

```bash
npm run check
npm test
```

## النشر على Hostinger VPS + HTTPS

وجّه سجل DNS من نوع A إلى عنوان VPS، افتح المنفذين 80 و443، ثم من `deploy/` أنشئ ملف `.env` يحتوي:

```env
ALSARH_DOMAIN=school.yourdomain.com
```

وشغّل:

```bash
cd deploy
docker compose up -d --build
```

Caddy يحصل على شهادة HTTPS تلقائيًا عندما يعمل DNS والمنفذان. لا تضع قواعد البيانات في مستودع عام، وجدول نسخًا احتياطية دورية لحجم `/data` منفصلة عن VPS مع تجربة استرجاعها. إعدادات خادم النسخ والاستعادة والمراقبة، وتصديق صلاحيات المؤسسة، ضرورية قبل نشر المدرسة على نطاق واسع.

## Android وWindows

- **Android**: مجلد `android` مشروع Android Studio أصلًا. يتطلب **رابط HTTPS منشور** عند أول فتح. GitHub Actions workflow `Build Android APK` يبني `app-debug.apk` للاختبار؛ إصدار المتجر يحتاج توقيع Release خاص وشروط النشر.
- **Windows**: مجلد `desktop` مشروع Electron مستقل. بعد `npm install` ثم `npm run build:win` ينتج Installer ونسخة محمولة عبر workflow `Build Windows Installer`. يتطلب رابط HTTPS لخادم المؤسسة.
- **Web/PWA**: جميع الواجهات تُخدَم من خادم Node نفسه، وتعمل في متصفح الكمبيوتر والجوال. الـPWA يخزن واجهة التطبيق للمساعدة عند ضعف الشبكة، **ولا يتيح تسجيل حسابات أو عمليات مالية دون اتصال**.

## حدود النسخة الأولى واحتياجات الإنتاج

هذه **نواة عملية أولية وليست منظومة مدرسية مكتملة أو جاهزة لاعتماد مدرسة فعلية دون اختبار واعتماد**. غير متوافر بعد: ملفات الطلبة المرفوعة بصيغة PDF، نظام امتحانات إلكترونية وأسئلة آلي، تصحيح ومراجعة متقدم، رسائل جماعية، بوابة دفع، جدولة الرواتب فعليًا، مؤشرات ذكاء اصطناعي، بنية متعددة الفروع والعام الدراسي بشكل شامل، استعادة النسخ بضغطة واحدة، دعم العملات المتعددة داخل نفس القيد، والمزامنة دون اتصال. النسخة الحالية لا تنشئ حسابات تلقائيًا ولا ترفع أسرارًا إلى GitHub.

**أمان وخصوصية:** شغّل HTTPS، لا تختبر ببيانات طلاب حقيقية قبل تدقيق الأمان والخصوصية والصلاحيات والاختبارات التشغيلية، وافصل بيئات التطوير والإنتاج. مستخدمو المدرسة لهم حسابات مستقلة؛ لا تُعطِ كلمة مرور المدير لأي شخص. الواجهة تستخدم صورًا وأيقونات محلية ولا تعتمد CDN أو VPN.
